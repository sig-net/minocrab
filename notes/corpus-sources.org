* Official: compiler, stdlib, tests

** LFDT-Minokawa/compact — THE motherlode (compiler + stdlib + test corpus)
- URL: https://github.com/LFDT-Minokawa/compact
- Contains: full Compact compiler source (Scheme), CLI (Rust), runtime (TS),
  formal spec (Agda), docs, and *568 .compact files*:
  - examples/ 496 files — this is effectively the compiler test corpus
    (adt, casts, bytes, errors, modules, vectors, types, ecdsa, secp256k1,
    std_lib, bugs/regressions, plus counter.compact, election.compact,
    zerocash.compact, proposal.compact, tiny.compact ...)
  - test-center/ 36 files, test-contracts/ 23 files, tools/ 8, misc 5
  - *Standard library source*: compiler/standard-library.compact
    (also compiler/zkir-v3-library.compact)
  - doc/lang-ref.mdx + doc/writing.mdx = authoritative language reference
- Version: HEAD of language development; CHANGELOG shows toolchain 0.33.122,
  language 0.25.107. Example pragmas span 0.12–0.16+ (many older regression
  tests) — good for version-spread coverage, but note some files
  intentionally test *errors* (examples/errors/, examples/bugs/).
- License: Apache-2.0
- Last updated: daily (Aug 2026), 1000+ commits
- Note: development home. Public releases are published to
  midnightntwrk/compact.

* Recommended shortlist (pull first)

1. *LFDT-Minokawa/compact* — 568 .compact files including the stdlib source
   (compiler/standard-library.compact) and the compiler's own example/test
   corpus; Apache-2.0; tracks the current language (0.25.x). This alone is
   ~80% of any corpus. Filter out examples/errors/ and examples/bugs/ if you
   want only-valid code, or keep them labeled as negative examples.
2. *OpenZeppelin/compact-contracts* — 75 files of idiomatic, reviewed,
   modern (>= 0.23) library code with tests; MIT.
3. *OpenZeppelin/midnight-apps* — 22 files of realistic DEX application
   code (>= 0.20).
4. *midnightntwrk example repos* (example-bboard, example-zkloan,
   example-kitties, example-counter, midnight-leaderboard) — only ~6 files
   total but canonical style, current pragmas, Apache-2.0; these are the
   patterns docs teach.
5. *midnightntwrk/midnight-docs* — 64 mdx files of embedded tutorial
   snippets, Apache-2.0; harvest fences for short-form idioms.

Then, for diversity of authorship/domain (games, DeFi, identity):
Luxion-Labs/REAP (11), hydra-stake-protocol (7), kaamos-otc (6),
bricktowers trio (identity/seabattle/rwa, 13 total), edda-contracts (5).
Mind the licenses: several community repos have NO license file — fine for
analysis, questionable for redistribution; prefer the licensed ones if the
corpus will be published.
