# signet-signer-interface

**The Sig Network signet signer's cross-contract interface, as an importable crate** for [MinoCrab](https://github.com/sig-net/minocrab) circuits. A Midnight contract that asks the Sig Network MPC for a signature calls the deployed signet signer; this crate declares that callee, so the call type-checks against the signer's own compactc artifact.

- `SignetSigner` — the callee, from an `#[interface]` trait: `sign_bidirectional`, `respond`, `respond_bidirectional`, with `SignetSigner::at_field(index)` (the sealed ledger cell a deployment keeps the address in) and `SignetSigner::at(address)`.
- `RequestId`, `Signature`, `AffinePoint`, `SignBidirectionalEventNotification`, `SignatureRespondedEventV1`, `RespondBidirectionalEventV1` — the argument types, field for field and in declaration order, which is the wire order hashed into the communications commitment.
- `notification::construct_notification_v1` — the callee's own constructor for the notification payload (hand-written; everything else is generated by `minocrab-interface-gen`).

The interface contains no address and no verifier key. `artifact/` ships beside the source: `pin.json` and `contract-info.json` are the compactc artifact the crate was generated from (the signet signer at midnight-integration v0.25.0, compiler 0.36.0), and `interface-schema.txt` is the frozen wire layout.

**Versioning follows the deployed contract's wire format, not the MinoCrab workspace.** Any change to `artifact/interface-schema.txt` (a reordered, retyped, added or removed argument, a renamed or removed circuit) is a major version; adding a circuit is minor; re-pinning to a same-signature redeploy is a patch. Most users get this crate through `minocrab-signet`.
