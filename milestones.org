#+title: MinoCrab Milestones

Working method: one milestone at a time, each session starts by reading this
file and any =notes/= file it links. Findings and decisions get written to
=notes/= as they're made, so no session ever re-derives them. Mark tasks DONE
in place.

* M0 — Foundations, corpus, and layer map
Everything here is research and setup; no eDSL code yet. The output is
written-down knowledge that every later milestone reads instead of rediscovering.
- [X] Nix flake + direnv; pin the Compact tooling (compactc etc.) in it.
      (compactc 0.33.0-rc.2 pinned by hash; verified: compiles corpus
      counter.compact → .zkir/.bzkir + keys. Mainnet stable 0.31.1 noted.)
- [X] Gather the corpus: clone sig-net Compact contracts (via gh) and public
      Midnight examples into =corpus/= (or as flake inputs). Compile each with
      the pinned compactc and keep the ZKIR output alongside the source.
      (corpus/: 8 pinned sources, 478 files (+195 negative), 312 compile OK
      incl. ALL 20 sig-net contracts — they need --feature-zkir-v3, wired as
      per-source flags. ./update.sh bumps pins. Failures recorded in
      compile-report.tsv are data, mostly older-pragma/multi-file cases.)
- [X] Survey Midnight's repos: what ZKIR crates/types/serializers exist that we
      can import or fork, which ZKIR version supports cross-contract calling,
      and how compactc drives the pipeline. Write to =notes/zkir.org= and
      =notes/midnight-code-reuse.org=.
- [X] Write the layer map (per plan.org: ZKIR bindings / rust IR + stdlib /
      optimisations / …) to =notes/architecture.org= before any implementation.
Exit criteria: corpus compiles reproducibly under nix; architecture doc exists;
we know exactly which Midnight code we're reusing and how.

* M2 — Core eDSL + native simulator
- [X] Minimal eDSL: wires, field/int ops, assertions, witness inputs, public
      outputs; lowering to ZKIR via M1.
      (crates/minocrab-ir: typed builder over all 26 ZKIR v2 instructions with
      arity tracking. crates/minocrab: Circuit/Wire API.)
- [X] Type-level disclosure tracking: =Wire<Private>= can't reach a public
      output without =disclose()=; overridable escape hatch; greppable.
      (Meet trait joins visibilities; declare_public/output only accept
      Wire<Public>; disclose(w, label) is the single gate and carries an
      audit label into the report. TODO M3: trybuild compile-fail test
      proving the type error.)
- [X] Native simulator running circuits in plain Rust inside =cargo test=, with
      structured output: performance metrics + what was disclosed.
      (crates/minocrab-sim mirrors midnight-ledger's reference VM;
      every run convertible to a ProofPreimage and cross-checked against
      IrSource::check in tests, so the simulator is never trusted alone.
      Report = op counts + witnesses consumed + labelled disclosed values,
      serde-serializable. cost() exposes their CircuitModel k/rows.)
Exit criteria: a small contract written in the eDSL lowers to valid ZKIR and
simulates with a disclosure report. MET — age-gate demo lowers, zkir
mock-compile accepts it, reference VM agrees with the simulator
(crates/minocrab-sim/tests/end_to_end.rs).

* M3 — Verification harness + cost profiler
- [ ] Spec-vs-circuit quickcheck/proptest harness: spec in ordinary Rust,
      millions of random inputs asserting circuit ≡ intent.
- [ ] Differential testing against compactc: same contract in Compact and in
      the eDSL, same inputs, same results.
- [ ] User-friendly cost profiler (constraint/RAM/proving-cost proxies, broken
      down by code region).
Exit criteria: the "obviously correct" story exists and is cheap to run in CI.

* M4 — stdlib + corpus rewrites
- [ ] Port the Compact stdlib pieces the corpus needs, mechanically translating
      Midnight's own implementations where possible.
- [ ] Rewrite the sig-net corpus contracts in the eDSL, one by one; each becomes

Exit criteria: the sig-net contracts run on MinoCrab with the M3 harness green.

* M5 — Optimisation
- [ ] Const-generic circuit families, monomorphized per size/depth, unrolled by
      rustc.
- [ ] Optimisation passes at the IR layer; measure with the M3 profiler against
      compactc's output (RAM + proving-cost proxies).
Exit criteria: measurable wins over compactc on the corpus, with the
correctness harness still green.

* M6 — Cross-contract calling + churn resilience
- [ ] Cross-contract calls in the eDSL on the ZKIR version that supports them.
- [ ] Documented, low-effort ZKIR/Compact-tooling version-bump workflow
      (update pin → run corpus + harness → fix drift).
Exit criteria: a version bump is a routine chore, not a project.

* M7 — Deliverable: cross-chain deposit/withdrawal benchmark
Benchmark the sig-net cross chain deposit and withdrawal contracts using
MinoCrab and using Compact, as a presentable deliverable (ideally showing
we're better than Compact).
Confirmed target (dmd, 2026-08-13): the erc20-vault contract
(sig-net/midnight-examples, examples/erc20-vault) — plus its Signet singleton
dependency (sig-net/midnight-integration) as needed for the cross-contract
calls. See notes/signet-corpus.org.
- [ ] Both contracts running under both toolchains at the same pinned versions,
      with the M3 correctness harness green on the MinoCrab versions.
- [ ] Head-to-head measurements: RAM, proving time, and constraint/cost-profiler
      breakdowns, reproducible via a single nix-run command.
- [ ] Presentable write-up of the results (methodology, numbers, where the wins
      come from; honest about any losses).
Exit criteria: a benchmark report you can present, reproducible from a clean
checkout.
